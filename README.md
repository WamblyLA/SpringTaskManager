### Менеджер заданий

Этот проект - небольшой бэкенд, написанный на Kotlin + Spring<br>
Он предоставляет методы управления заданиями и пользователями, регистрацию и возможность присвоить задание пользователю<br>
В проекте присутствует swagger - он будет развернут по адресу<br>
```
http://localhost:8080/docs
```
Чтобы запустить проект, нужно из корня
1. Собрать jar:
```bash
./gradlew clean bootJar
```
2. Поднять Docker
```bash
docker compose up --build
```

Проект запустится на порту `8080`
